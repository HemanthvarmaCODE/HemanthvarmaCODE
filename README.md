## `→ What I Have Built`

**`Latent Sentry`** — Rust · eBPF  
A kernel-level security tool that attaches eBPF probes to monitor CPU and syscall activity in real time. Designed to detect behavioural signatures of rootkits and spyware before they can establish persistence on the host. Written entirely in Rust for memory safety without runtime overhead.

**`Transaction Ledger`** — Java · Spring Boot · Apache Kafka  
An enterprise-grade financial transaction ledger built on an event-driven architecture. Kafka handles the event stream backbone, ensuring durable, ordered transaction processing with full audit trail support. Designed with the principles of high-throughput, fault-tolerant distributed systems.
